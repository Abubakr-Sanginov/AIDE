История
версий

Здесь появляется каждая новая версия редактора.

v0.3.1Текущая версия

Агент доводит работу до конца

  • Исчез служебный текст в конце ответов (список вызовов инструментов и обрывки тегов): прошлые ответы теперь передаются модели короткими строками, а не JSON, а то, что всё же просочилось, вырезается.
  • Если модель остановилась, а в плане остались шаги, или только пообещала действие и не вызвала инструмент, она получает команду продолжить.
  • Инструмент плана понимает неточно заданные аргументы, и ошибки «invalid arguments» стало меньше.
v0.3.0

«Студия 3D» теперь и во Vibe

  • В режиме Vibe появилась вкладка «Студия 3D» рядом с «Агентом», «Компьютером» и «Экипажем»: превью снимков вьюпорта, рендеров и моделей над чатом студии.
  • В остальном 0.3.0 включает всё из 0.2.x: агент сам составляет план, действия с сообщениями, поиск ключей из переменных окружения, режимы «Компьютер» и «Студия 3D».
v0.2.9

Студия 3D, действия с сообщениями, новый «Контекст»

  • Новый режим «Студия 3D»: агент работает с Blender, Unity, Unreal Engine и Godot через их серверы MCP (готовые пресеты в настройках), знает рабочие приёмы из встроенных навыков и показывает снимки вьюпорта и рендеры в превью прямо в приложении.
  • У сообщений в чате появились действия: копировать, изменить вопрос и отправить заново, ответить заново, удалить.
  • Вкладка «Контекст» стала нагляднее: цветная полоса заполнения окна и список, из чего оно состоит (сообщения, инструменты, MCP, промпт, навыки, память и правила проекта).
v0.2.8

Ключи из переменных окружения находятся сами

  • Если ключ агента записан как [code]$NAME[/code], AIDE ищет значение в окружении, в переменных Windows (перезапуск AIDE не нужен), в блоке [code]env[/code] настроек агента и в файле [code].env[/code].
  • Если значения нет нигде, сообщение об ошибке подсказывает, куда его добавить.
v0.2.7

Агент сам составляет план

  • Для сложной задачи агент сначала записывает короткий план, а по ходу работы отмечает выполненные шаги. План виден карточкой в чате и во вкладке «Контекст».
  • Кнопка правой панели в Vibe и «Дизайне» теперь со значком панели вместо глобуса и открывает панель на последней вкладке: по умолчанию «Контекст» с планом.
  • Режим «План» остался для случаев, когда нужен только план без правок файлов.
v0.2.6

Vibe: контекст рядом с браузером, ключи из окружения

  • В Vibe и «Дизайне» справа вкладки «Контекст» и «Браузер»: план и заполнение окна — рядом со страницей.
  • Ключи агентов вида [code]$T3_DEEPAI_TOKEN[/code] теперь раскрываются из переменных окружения, а не сохраняются как текст [code]$NAME[/code] — ошибка 403 «Model transport authentication required» ушла.
v0.2.5

Правая панель: вкладки и контекст

  • «Контекст» стоит в одном ряду с «Браузером» и открывается рядом с ним.
  • Вкладки правой панели всегда помещаются по ширине: длинные названия сокращаются, за край ничего не уезжает.
  • Разделы «Контекста» идут друг под другом: окружение, заполнение окна, план и история сжатия.
v0.2.4

Контекст, план и сжатие

  • Вкладка «Контекст» в правой панели: заполнение окна модели, стоимость сообщений и вызовов инструментов, вложения и активный файл.
  • План: шаги ответа в режиме «План» показываются списком, выполненные пункты отмечаются.
  • Команда /compact: переписка сворачивается в одно резюме, а прежние сообщения остаются на экране.
v0.2.3

Обновление из приложения

  • Приложение обновляет себя само: новая версия скачивается и ставится прямо из AIDE.
  • Релизы собираются и подписываются на GitHub — файлы обновления проверяются подписью.
  • Имя автора в правом верхнем углу окна.
  • Кнопка «Скачать» на сайте: установщик ставится в один клик.
v0.1.1

Студия в одном окне

Редактор

  • Редактор на CodeMirror 6: подсветка, поиск, сворачивание, мультикурсор, diff.
  • Дерево проекта, терминалы во вкладках, панель Git, поиск по проекту.
  • Палитра команд, недавние проекты, сниппеты.
  • Встроенный браузер с консолью; фото, видео и PDF открываются во вкладке.

ИИ

  • Агент с разрешениями, отчётом о действиях, подсчётом токенов, откатом и кнопкой «Стоп».
  • Правка выделенного кода по Ctrl+K с превью изменений.
  • Режим Vibe и Экипаж из двенадцати ролей с лицами, голосами и навыками.
  • Режим Дизайн: холст, слои и создание проекта в выбранном стеке.
  • MCP-серверы, правила проекта из AGENTS.md и свои команды чата.

Безопасность и интерфейс

  • Ключи API в хранилище учётных данных Windows.
  • Интерфейс на 11 языках.
