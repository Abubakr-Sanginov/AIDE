AIDE Dokumentation

So arbeiten Sie
mit AIDE

Kurze Anleitungen zum Wichtigsten: vom ersten Start bis zu eigenen Befehlen für den Agenten.

Erste Schritte

  1. Installieren Sie Node.js 20+, Rust und die Tauri-2-Voraussetzungen für Windows.
  2. Führen Sie im Projektordner npm install und dann npm run tauri dev aus.
  3. Öffnen Sie Ihren Code-Ordner: Strg+O.
  4. Verbinden Sie in den Einstellungen ein Modell. Der API-Schlüssel wird in der Windows-Anmeldeinformationsverwaltung gespeichert, nicht in Dateien.

Drei Modi

Der Schalter im Fensterkopf ändert die ganze Oberfläche. Projekt, Verlauf und Agent bleiben dieselben.

IDE
Ein Editor auf Basis von CodeMirror 6, Dateibaum, Terminals in Tabs, Git und Suche. Der Agent sitzt im Chat rechts.
Vibe
Beschreiben Sie das Ergebnis in Worten. Der Teamlead zerlegt die Aufgabe in Schritte, die Rollen setzen sie um, QA prüft.
Design
Bauen Sie ein Mockup auf der Leinwand, klicken Sie dann auf „Im Projekt erstellen“ und wählen Sie einen Stack: HTML, React, Vue, Svelte, Next.js oder Astro.

Agent

  • Berechtigungen. Dateien schreiben und Terminalbefehle ausführen – erst nach Ihrem „Erlauben“.
  • Bericht. Am Ende jeder Antwort steht eine Liste der Aktionen, z. B. „Erledigt: 6 Aktionen ›“, und die Zahl der verbrauchten Tokens.
  • Rückgängig. Vor jeder Änderung entsteht ein Checkpoint. Der Knopf „Rückgängig“ stellt die geänderten Dateien wieder her.
  • Stopp. Bricht die Anfrage an das Modell sofort ab.
  • Auswahl bearbeiten. Code markieren und Strg+K drücken: Die Änderungen erscheinen als Diff zum Annehmen oder Ablehnen.

Crew

Zwölf Rollen mit Gesichtern, Stimmen und Fähigkeiten: Teamlead, Design, Frontend, Backend, QA, DevOps, Analyst, Jurist, Buchhaltung, Marketing, Praktikant und Spaßvogel. Sie sind der CEO: Sie stellen die Aufgabe, die Rollen besprechen sie und teilen die Arbeit auf.

Nur Rollen mit „Händen“ dürfen Dateien ändern und Befehle ausführen – die anderen beraten und prüfen. Aktionen der Rollen laufen über dieselben Berechtigungen wie die des Agenten.

Regeln und Befehle

Legen Sie AGENTS.md oder CLAUDE.md ins Projektstammverzeichnis – der Agent liest diese Regeln vor der Arbeit.

Eigene Chat-Befehle: Legen Sie eine Datei .aide/commands/name.md mit dem Prompt an. Im Chat erscheint sie als /name, und $ARGUMENTS wird durch das ersetzt, was Sie nach dem Befehl schreiben.
