03 Controllo

Le chiavi non lasciano
la macchina

Le chiavi API stanno nel gestore credenziali di Windows. Le azioni rischiose aspettano la tua conferma, prima di ogni modifica dell'agente si crea un checkpoint e «Stop» interrompe subito la richiesta.
