AIDE Documentazione

Come lavorare
in AIDE

Brevi guide all'essenziale: dal primo avvio ai tuoi comandi per l'agente.

Per iniziare

  1. Installa Node.js 20+, Rust e i prerequisiti di Tauri 2 per Windows.
  2. Nella cartella del progetto esegui npm install, poi npm run tauri dev.
  3. Apri la cartella del codice: Ctrl+O.
  4. Collega un modello nelle impostazioni. La chiave API viene salvata nel gestore credenziali di Windows, non nei file.

Tre modalità

Il selettore nell'intestazione della finestra cambia tutta l'interfaccia. Progetto, cronologia e agente restano gli stessi.

IDE
Un editor basato su CodeMirror 6, albero dei file, terminali a schede, Git e ricerca. L'agente è nella chat a destra.
Vibe
Descrivi il risultato a parole. Il team lead divide il compito in passi, i ruoli li eseguono, il QA controlla.
Design
Crea un mockup sulla tela, poi premi «Crea nel progetto» e scegli uno stack: HTML, React, Vue, Svelte, Next.js o Astro.

Agente

  • Permessi. Scrivere file ed eseguire comandi nel terminale solo dopo il tuo «Consenti».
  • Report. Ogni risposta termina con l'elenco delle azioni, ad esempio «Fatto: 6 azioni ›», e i token spesi.
  • Annulla. Prima di ogni modifica si crea un checkpoint. Il pulsante «Annulla» ripristina i file modificati.
  • Stop. Interrompe all'istante la richiesta al modello.
  • Modifica della selezione. Seleziona il codice e premi Ctrl+K: le modifiche compaiono come diff da accettare o rifiutare.

Equipaggio

Dodici ruoli con volti, voci e competenze: team lead, design, front, back, QA, DevOps, analista, legale, contabile, marketing, stagista e burlone. Tu sei il CEO: assegni il compito, i ruoli ne discutono e si dividono il lavoro.

Solo i ruoli con le «mani» possono modificare file ed eseguire comandi — gli altri consigliano e verificano. Le loro azioni passano per gli stessi permessi dell'agente.

Regole e comandi

Metti AGENTS.md o CLAUDE.md nella radice del progetto: l'agente legge queste regole prima di lavorare.

Comandi di chat personalizzati: crea un file .aide/commands/nome.md con il prompt. In chat appare come /nome e $ARGUMENTS viene sostituito da ciò che scrivi dopo il comando.
