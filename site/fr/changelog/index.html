AIDE Nouveautés

Historique
des versions

Chaque nouvelle version de l'éditeur apparaît ici.

v0.2.8Version actuelle

Les clés des variables d’environnement sont trouvées toutes seules

  • Quand une clé d’agent est écrite $NAME, AIDE cherche la valeur dans l’environnement, dans les variables Windows (pas besoin de redémarrer AIDE), dans le bloc env des réglages de l’agent et dans un fichier .env.
  • Si la valeur est introuvable, le message d’erreur indique où l’ajouter.
v0.2.7

L’agent planifie lui-même

  • Pour une tâche complexe, l’agent écrit d’abord un court plan et coche les étapes au fil du travail. Le plan s’affiche sous forme de carte dans le chat et dans l’onglet « Contexte ».
  • Le bouton du panneau de droite dans Vibe et « Design » a désormais une icône de panneau au lieu d’un globe et ouvre le dernier onglet utilisé : « Contexte », avec le plan, par défaut.
  • Le mode Plan reste disponible quand vous voulez seulement un plan, sans modification de fichiers.
v0.2.6

Vibe : le contexte à côté du navigateur, clés depuis l’environnement

  • Dans Vibe et « Design », la partie de droite propose les onglets « Contexte » et « Navigateur » : le plan et le remplissage de la fenêtre sont à côté de la page.
  • Les clés d’agent comme $T3_DEEPAI_TOKEN sont maintenant développées depuis les variables d’environnement au lieu d’être stockées littéralement ($NAME) — l’erreur 403 « Model transport authentication required » a disparu.
v0.2.5

Panneau de droite : onglets et contexte

  • « Contexte » se trouve sur la même ligne que « Navigateur » et s'ouvre à côté.
  • Les onglets du panneau de droite tiennent toujours dans la largeur : les noms longs sont abrégés, rien ne dépasse.
  • Les sections de « Contexte » sont empilées : environnement, remplissage de la fenêtre, plan et historique des compressions.
v0.2.4

Contexte, plan et compactage

  • Un onglet « Contexte » dans le panneau de droite : le remplissage de la fenêtre du modèle, le coût des messages et des appels d'outils, les pièces jointes et le fichier actif.
  • Plan : les étapes d'une réponse en mode Plan s'affichent en liste, les points faits sont marqués.
  • La commande /compact : la conversation se réduit à un résumé, les messages précédents restent à l'écran.
v0.2.3

Mises à jour depuis l'application

  • L'application se met à jour elle-même : la nouvelle version se télécharge et s'installe depuis AIDE.
  • Les versions sont compilées et signées sur GitHub — les fichiers de mise à jour sont vérifiés par signature.
  • Le nom de l'auteur dans le coin supérieur droit de la fenêtre.
  • Un bouton Télécharger sur le site : l'installateur en un clic.
v0.1.1

Un studio dans une fenêtre

Éditeur

  • Éditeur basé sur CodeMirror 6 : coloration, recherche, repli, curseurs multiples, diff.
  • Arborescence du projet, terminaux en onglets, panneau Git, recherche dans le projet.
  • Palette de commandes, projets récents, snippets.
  • Navigateur intégré avec console ; photos, vidéos et PDF s'ouvrent dans un onglet.

IA

  • Un agent avec autorisations, rapport d'actions, décompte des tokens, annulation et bouton « Stop ».
  • Modification du code sélectionné avec Ctrl+K et aperçu des changements.
  • Mode Vibe et un équipage de douze rôles avec visages, voix et compétences.
  • Mode Design : canevas, calques et création d'un projet dans le stack choisi.
  • Serveurs MCP, règles de projet depuis AGENTS.md et commandes de chat personnalisées.

Sécurité et interface

  • Clés d'API dans le gestionnaire d'identifiants de Windows.
  • Interface en 11 langues.
