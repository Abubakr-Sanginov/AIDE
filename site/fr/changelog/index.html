v0.1.1Version actuelle

Un studio dans une fenêtre

Éditeur

  • Éditeur basé sur CodeMirror 6 : coloration, recherche, repli, curseurs multiples, diff.
  • Arborescence du projet, terminaux en onglets, panneau Git, recherche dans le projet.
  • Palette de commandes, projets récents, snippets.
  • Navigateur intégré avec console ; photos, vidéos et PDF s'ouvrent dans un onglet.

IA

  • Un agent avec autorisations, rapport d'actions, décompte des tokens, annulation et bouton « Stop ».
  • Modification du code sélectionné avec Ctrl+K et aperçu des changements.
  • Mode Vibe et un équipage de douze rôles avec visages, voix et compétences.
  • Mode Design : canevas, calques et création d'un projet dans le stack choisi.
  • Serveurs MCP, règles de projet depuis AGENTS.md et commandes de chat personnalisées.

Sécurité et interface

  • Clés d'API dans le gestionnaire d'identifiants de Windows.
  • Interface en 11 langues.
