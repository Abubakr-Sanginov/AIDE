AIDE Documentation

Travailler
avec AIDE

De courts guides sur l'essentiel : du premier lancement à vos propres commandes pour l'agent.

Premiers pas

  1. Installez Node.js 20+, Rust et les prérequis de Tauri 2 pour Windows.
  2. Dans le dossier du projet, lancez npm install, puis npm run tauri dev.
  3. Ouvrez votre dossier de code : Ctrl+O.
  4. Connectez un modèle dans les réglages. La clé d'API est stockée dans le gestionnaire d'identifiants de Windows, pas dans des fichiers.

Trois modes

L'interrupteur dans l'en-tête de la fenêtre change toute l'interface. Le projet, l'historique et l'agent restent les mêmes.

IDE
Un éditeur basé sur CodeMirror 6, l'arborescence, des terminaux en onglets, Git et la recherche. L'agent est dans le chat à droite.
Vibe
Décrivez le résultat avec vos mots. Le chef d'équipe découpe la tâche en étapes, les rôles les exécutent, la QA vérifie.
Design
Assemblez une maquette sur le canevas, puis cliquez sur « Créer dans le projet » et choisissez un stack : HTML, React, Vue, Svelte, Next.js ou Astro.

Agent

  • Autorisations. Écrire des fichiers et lancer des commandes dans le terminal : seulement après votre « Autoriser ».
  • Rapport. Chaque réponse se termine par la liste des actions, par exemple « Terminé : 6 actions › », et le nombre de tokens dépensés.
  • Annulation. Un point de restauration est créé avant toute modification. Le bouton « Annuler » rétablit les fichiers modifiés.
  • Stop. Coupe instantanément la requête au modèle.
  • Modifier une sélection. Sélectionnez du code et appuyez sur Ctrl+K : les changements s'affichent en diff, à accepter ou refuser.

Équipage

Douze rôles avec visages, voix et compétences : chef d'équipe, design, front, back, QA, DevOps, analyste, juriste, comptable, marketing, stagiaire et blagueur. Vous êtes le CEO : vous posez la tâche, les rôles en discutent et se partagent le travail.

Seuls les rôles qui ont des « mains » peuvent modifier des fichiers et lancer des commandes — les autres conseillent et vérifient. Leurs actions passent par les mêmes autorisations que celles de l'agent.

Règles et commandes

Placez AGENTS.md ou CLAUDE.md à la racine du projet — l'agent lit ces règles avant de commencer.

Vos propres commandes de chat : créez un fichier .aide/commands/nom.md avec le prompt. Il apparaît dans le chat comme /nom, et $ARGUMENTS est remplacé par ce que vous écrivez après la commande.
