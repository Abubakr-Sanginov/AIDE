AIDE Документация

Как работать
в AIDE

Подробное руководство: от первого запуска до своих команд для агента, проверок, обновлений и разбора частых проблем.

Начало работы

AIDE — настольный редактор кода со встроенной ИИ-студией: агент, дизайн-холст и команда из двенадцати ролей работают в одном окне. Ниже — короткий путь от установки до первой правки.

  1. Установите Node.js 20+, Rust и зависимости Tauri 2 для Windows — это нужно только если вы собираете редактор из исходников.
  2. В папке проекта выполните npm install, затем npm run tauri dev для разработки или npm run tauri build для установщика.
  3. Откройте папку с кодом: Ctrl+O. Недавние проекты доступны по Ctrl+R.
  4. Подключите модель в настройках. Ключ API сохраняется в хранилище учётных данных Windows, а не в файлах проекта.
  5. Напишите задачу в чате справа. Агент предложит план, попросит разрешения на запись файлов и команд и покажет итог с числом потраченных токенов.

Если вы просто пользуетесь установщиком, Node.js и Rust не нужны — внутри уже всё есть.

Установка и обновление

Готовый установщик лежит на этом сайте: кнопка «Скачать для Windows» в разделе «Запуск». Нужны Windows 10 или 11 и WebView2 — на актуальных сборках он уже установлен.

  • Сборка из исходников. npm install, затем npm run tauri build. Готовые файлы появятся в папке bundle рядом с проектом: установщик NSIS и пакет MSI.
  • Обновления приходят сами. AIDE раз в сутки сверяет свою версию с последним релизом на GitHub и предлагает обновиться. Кнопку проверки можно нажать и вручную.
  • Подпись. Файлы обновления проверяются криптографической подписью: сборке из чужого источника приложение не поверит.
  • Предупреждение Windows. Установщик не подписан платным сертификатом издателя, поэтому SmartScreen может спросить подтверждение при первом запуске. На работу редактора это не влияет.
  • Удаление. Обычное удаление программы в параметрах Windows. Проекты, настройки и ключи при этом остаются на месте — удаляются отдельно, если нужны.

Рабочее пространство

Слева — дерево проекта. Файлы и папки создаются, переименовываются и удаляются из контекстного меню, а изменения на диске подхватываются сразу: правка снаружи не потеряется.

  • Вкладки. Держат позицию курсора и историю отмены, закрываются средней кнопкой мыши. Картинки, PDF и шрифты открываются для просмотра прямо в редакторе.
  • Панели. Проводник, поиск по проекту, Git, сниппеты и расширения переключаются в левой панели и не мешают друг другу.
  • Поиск по тексту. Ctrl+Shift+F ищет с учётом регистра и по маске файлов.
  • Поиск по смыслу. Запрос вроде «parse config file» находит нужные места, даже если в коде другие слова: имена функций и путей учитываются отдельно от текста.
  • Палитра команд. Ctrl+P — быстрый доступ к файлам и действиям без мыши.

Редактор и языки

Редактор построен на CodeMirror 6: подсветка, номера строк, автодополнение, поиск и замена, мультикурсор и сворачивание блоков.

  • Языковые серверы. Подсказки по типам, подчёркивание ошибок, переход к определению и обратно, переименование символа и форматирование файла — те же серверы, что использует VS Code.
  • Без сервера тоже работает. Если языковой сервер для языка не установлен, остаются подсветка, навигация и поиск по символам.
  • Конфликты Git. Показываются как merge-view: принять свою или чужую сторону можно кнопкой, руками править файл не обязательно.
  • Правка агентом. Ctrl+K на выделенном коде — агент предложит новую версию, а вы примете или отклоните её по diff.

Чат и модели

Поддерживаются OpenAI, Anthropic, Google и любые совместимые серверы: адрес и список моделей задаются в настройках провайдера.

  • Локальные модели. Ollama или LM Studio на этом компьютере — тогда запросы не покидают машину.
  • Ключи. Хранятся в Credential Manager Windows, отдельно для каждого провайдера. Ключ не попадает ни в проект, ни в ответ модели, ни в журнал.
  • Токены. В каждом ответе видно, сколько потрачено, — можно сравнивать модели по цене, а не на глаз.
  • История. Живёт в проекте: вернулись к папке — разговор продолжается с того же места.
  • Вложения. К сообщению можно приложить файл или картинку, текст из него попадёт в контекст модели.
  • Очередь. Если агент ещё работает, новое сообщение встаёт в очередь, а стрелка рядом отправляет его немедленно и останавливает текущий ответ.

Три режима

Переключатель в шапке окна меняет весь интерфейс. Проект, история и агент при этом остаются те же.

IDE
Редактор на CodeMirror 6, дерево файлов, терминалы во вкладках, Git и поиск. Агент — в чате справа.
Vibe
Опишите результат словами. Тимлид разложит задачу на шаги, роли выполнят их, QA проверит.
Дизайн
Соберите макет на холсте, а потом нажмите «Создать в проекте» и выберите стек: HTML, React, Vue, Svelte, Next.js или Astro.

Агент

  • Разрешения. Запись файлов и команды в терминале выполняются только после вашего «Разрешить».
  • Отчёт. В конце ответа — список действий, например «Выполнено: 6 действий ›», и число потраченных токенов.
  • Чекпоинты. Перед правками снимается снимок: «Отменить» возвращает файлы к состоянию до работы агента.
  • Остановка. Кнопка «Стоп» прерывает ответ, уже сделанное остаётся — его можно принять или откатить.
  • Инструменты. Чтение и запись файлов, поиск по проекту и по смыслу, терминал, git, страницы в интернете, проверки и диагностика.
  • Уточнения. Если задача допускает разные толкования, агент сначала спрашивает, а потом делает — и не придумывает за вас.

Терминал и Git

  • Настоящий pty. Работают интерактивные программы, цвета, стрелки и Ctrl+C. Вкладок терминала может быть сколько нужно.
  • Git-панель. Изменённые файлы, diff построчно, ветка и история; коммит делается оттуда же.
  • Команды агента. Он может запускать их сам, но только с вашего подтверждения: перед запуском видно, что именно будет выполнено.

Проверки качества

  • После правок. AIDE запускает проверки проекта — типы, линтер, тесты — и присылает результат, если что-то сломалось.
  • Перед словом «готово». Навык проверки перед сдачей требует перечитать diff, собрать проект и прогнать тесты.
  • Диагностика. Ошибки языковых серверов видны сразу в панели задач, ещё до запуска проекта.
  • Отключение. Самопроверку можно выключить в настройках, если проект большой и проверки идут долго.

Экипаж

  • Двенадцать ролей: тимлид, дизайн, фронт, бэк, QA, девопс, аналитик, юрист, бухгалтер, маркетолог, стажёр и шутник.
  • Роли не спорят между собой бесконечно: тимлид распределяет работу и сводит результат, QA проверяет каждую задачу.

Вы — CEO: решаете, что из предложенного попадёт в код.

Правила и команды

Положите AGENTS.md или CLAUDE.md в корень проекта — агент прочитает эти правила перед работой.

Свои команды для чата: создайте файл .aide/commands/имя.md с текстом запроса. В чате он появится как /имя, а вместо $ARGUMENTS подставится то, что вы напишете после команды.

Правила проекта сильнее привычек агента: если файл запрещает менять что-то — агент спросит, а не сделает молча.

Безопасность и данные

  • Ключи. В Credential Manager Windows. В проекте, репозитории и журналах их нет.
  • Разрешения. Запись файлов, команды и выход в интернет — только после подтверждения.
  • Ваш код. Остаётся на диске: AIDE отправляет его только в выбранную вами модель.
  • Локальная модель. Тогда из компьютера не уходит вообще ничего.
  • Телеметрии нет. Приложение не собирает статистику использования и не шлёт скрытых отчётов.

Настройки

  • Внешний вид. Язык интерфейса, тема, размер шрифта редактора, поведение панелей и терминала.
  • Провайдеры. Свой список моделей — для серверов, которые не умеют отдавать его сами.
  • Навыки. Встроенные наборы правил включаются и выключаются: проверка перед сдачей, аккуратные правки, безопасный код, отладка, тесты, фронтенд.
  • Права. Что агенту разрешено без вопроса, а что всегда требует подтверждения.

Частые вопросы

Нужны ли Node.js и Rust, чтобы просто пользоваться AIDE?
Нет. В установщике уже есть всё, что нужно приложению. Node нужен только для проверок вашего проекта, а Rust — если вы собираете AIDE сами.
Куда уходит мой код?
Только в выбранную вами модель. С локальной моделью — никуда.
Где хранятся ключи API?
В хранилище учётных данных Windows, отдельно для каждого провайдера, в зашифрованном виде.
Можно ли работать без интернета?
Да, если модель запущена локально: редактор, терминал и Git работают всегда, а агент — с локальной моделью.
Что будет, если агент ошибётся?
Перед правками снимается чекпоинт, «Отменить» возвращает файлы. Разрешения не дают сделать что-то без вашего согласия.
AIDE работает на macOS или Linux?
Сейчас сборка выпускается для Windows. Код на Tauri и React переносим, но готовых сборок для других систем нет.
Как обновиться?
Само: приложение проверит обновление и предложит установить. Или скачайте новый установщик на этом сайте.
Почему Windows предупреждает при установке?
Установщик не подписан платным сертификатом издателя — это предупреждение SmartScreen, а не вирус. Подпись самих обновлений проверяется отдельно.

Если что-то не работает

  • Модель не отвечает. Проверьте ключ и адрес провайдера в настройках и доступ к интернету. Ошибка 401 — неверный ключ, 429 — превышен лимит запросов.
  • Не устанавливается. Закройте запущенный AIDE и повторите установку.
  • Пропали панели. Ctrl+B и Ctrl+J возвращают боковую панель и терминал.
  • Терминал пустой. Откройте новую вкладку терминала — старая сессия могла завершиться.
  • Нет подсветки или подсказок. Для языка может не хватать языкового сервера: установите его в системе, и редактор подхватит его сам.
  • Проверки падают. Пришлите вывод проверок в чат — агент прочитает ошибку и исправит причину, а не следствие.
