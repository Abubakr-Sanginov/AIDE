AIDE Документация

Как работать
в AIDE

Короткие руководства по главному: от первого запуска до своих команд для агента.

Начало работы

  1. Установите Node.js 20+, Rust и зависимости Tauri 2 для Windows.
  2. В папке проекта выполните npm install, затем npm run tauri dev.
  3. Откройте папку с кодом: Ctrl+O.
  4. Подключите модель в настройках. Ключ API сохраняется в хранилище учётных данных Windows, а не в файлах.

Три режима

Переключатель в шапке окна меняет весь интерфейс. Проект, история и агент при этом остаются те же.

IDE
Редактор на CodeMirror 6, дерево файлов, терминалы во вкладках, Git и поиск. Агент — в чате справа.
Vibe
Опишите результат словами. Тимлид разложит задачу на шаги, роли выполнят их, QA проверит.
Дизайн
Соберите макет на холсте, а потом нажмите «Создать в проекте» и выберите стек: HTML, React, Vue, Svelte, Next.js или Astro.

Агент

  • Разрешения. Запись файлов и команды в терминале выполняются только после вашего «Разрешить».
  • Отчёт. В конце ответа — список действий, например «Выполнено: 6 действий ›», и число потраченных токенов.
  • Откат. Перед правками создаётся чекпоинт. Кнопка «Отменить» возвращает изменённые файлы.
  • Стоп. Мгновенно обрывает запрос к модели.
  • Правка выделенного. Выделите код и нажмите Ctrl+K: изменения покажутся как diff, их можно принять или отклонить.

Экипаж

Двенадцать ролей с лицами, голосами и навыками: тимлид, дизайн, фронт, бэк, QA, девопс, аналитик, юрист, бухгалтер, маркетолог, стажёр и шутник. Вы — CEO: ставите задачу, а роли обсуждают её и делят работу.

Менять файлы и запускать команды могут только роли с «руками» — остальные советуют и проверяют. Действия ролей проходят через те же разрешения, что и действия агента.

Правила и команды

Положите AGENTS.md или CLAUDE.md в корень проекта — агент прочитает эти правила перед работой.

Свои команды для чата: создайте файл .aide/commands/имя.md с текстом запроса. В чате он появится как /имя, а вместо $ARGUMENTS подставится то, что вы напишете после команды.
