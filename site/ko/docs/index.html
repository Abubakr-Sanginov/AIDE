AIDE
사용법

핵심만 담은 짧은 가이드: 첫 실행부터 에이전트용 나만의 명령까지.

시작하기

  1. Node.js 20+, Rust, Windows용 Tauri 2 필수 구성 요소를 설치하세요.
  2. 프로젝트 폴더에서 npm install을 실행한 다음 npm run tauri dev를 실행하세요.
  3. 코드 폴더 열기: Ctrl+O.
  4. 설정에서 모델을 연결하세요. API 키는 파일이 아니라 Windows 자격 증명 관리자에 저장됩니다.

세 가지 모드

창 상단의 스위치로 인터페이스 전체가 바뀝니다. 프로젝트, 기록, 에이전트는 그대로입니다.

IDE
CodeMirror 6 기반 에디터, 파일 트리, 탭 터미널, Git, 검색. 에이전트는 오른쪽 채팅에 있습니다.
Vibe
결과를 말로 설명하세요. 팀 리드가 작업을 단계로 나누고, 역할들이 수행하며, QA가 확인합니다.
디자인
캔버스에서 목업을 만든 다음 「프로젝트에 생성」을 누르고 스택을 고르세요: HTML, React, Vue, Svelte, Next.js, Astro.

에이전트

  • 권한. 파일 쓰기와 터미널 명령 실행은 당신이 「허용」한 뒤에만.
  • 보고. 답변 끝에 「완료: 작업 6개 ›」 같은 작업 목록과 사용한 토큰 수가 표시됩니다.
  • 되돌리기. 수정 전에 체크포인트가 만들어집니다. 「되돌리기」 버튼으로 바뀐 파일을 복원합니다.
  • 중지. 모델에 보낸 요청을 즉시 끊습니다.
  • 선택 영역 수정. 코드를 선택하고 Ctrl+K를 누르세요. 변경 사항이 diff로 표시되고 수락하거나 거부할 수 있습니다.

크루

얼굴, 목소리, 스킬을 가진 열두 역할: 팀 리드, 디자인, 프론트, 백엔드, QA, 데브옵스, 분석가, 법무, 회계, 마케터, 인턴, 분위기 메이커. CEO는 당신입니다. 작업을 맡기면 역할들이 논의하고 일을 나눕니다.

파일을 바꾸고 명령을 실행할 수 있는 건 「손」이 있는 역할뿐이고, 나머지는 조언하고 검토합니다. 역할의 작업도 에이전트와 같은 권한 절차를 거칩니다.

규칙과 명령

프로젝트 루트에 AGENTS.md 또는 CLAUDE.md를 두면 에이전트가 작업 전에 그 규칙을 읽습니다.

나만의 채팅 명령: 프롬프트를 담은 .aide/commands/이름.md 파일을 만드세요. 채팅에 /이름으로 나타나고, $ARGUMENTS는 명령 뒤에 입력한 내용으로 바뀝니다.
