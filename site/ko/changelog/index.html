v0.1.1현재 버전

한 창 안의 스튜디오

에디터

  • CodeMirror 6 기반 에디터: 하이라이트, 검색, 접기, 멀티 커서, diff.
  • 프로젝트 트리, 탭 터미널, Git 패널, 프로젝트 검색.
  • 명령 팔레트, 최근 프로젝트, 스니펫.
  • 콘솔이 있는 내장 브라우저. 사진, 동영상, PDF도 탭에서 열립니다.

AI

  • 권한, 작업 보고, 토큰 집계, 되돌리기, 「중지」 버튼을 갖춘 에이전트.
  • Ctrl+K로 선택한 코드를 수정하고 변경 사항을 미리 보기.
  • Vibe 모드와 얼굴, 목소리, 스킬을 가진 열두 역할의 크루.
  • 디자인 모드: 캔버스, 레이어, 선택한 스택으로 프로젝트 생성.
  • MCP 서버, AGENTS.md의 프로젝트 규칙, 사용자 채팅 명령.
