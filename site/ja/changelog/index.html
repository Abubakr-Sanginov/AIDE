AIDE 新機能

バージョン
履歴

エディターの新しいバージョンはここに載ります。

v0.2.8現在のバージョン

環境変数のキーを自動で見つける

  • エージェントのキーが $NAME と書かれている場合、AIDE は環境、Windows の変数（AIDE の再起動は不要）、エージェント設定の env ブロック、.env ファイルから値を探します。
  • どこにも値がない場合は、エラーメッセージが追加すべき場所を案内します。
v0.2.7

エージェントが自分で計画を立てる

  • 複雑なタスクでは、エージェントがまず短い計画を書き、作業しながら手順にチェックを入れます。計画はチャットと「コンテキスト」タブにカードで表示されます。
  • VibeとDesignの右パネルのボタンは、地球儀ではなくパネルのアイコンになり、最後に使ったタブで開きます。既定は計画つきの「コンテキスト」です。
  • 計画モードは、ファイルを変更せず計画だけが欲しいときのために残っています。
v0.2.6

Vibe：ブラウザの隣のコンテキスト、環境変数のキー

  • Vibe と「デザイン」では、右側に「コンテキスト」と「ブラウザ」のタブがあります。計画とウィンドウの使用量がページの隣に表示されます。
  • $T3_DEEPAI_TOKEN のようなエージェントキーは、$NAME という文字列として保存されるのではなく環境変数から展開されます。「Model transport authentication required」の 403 エラーは出なくなりました。
v0.2.5

右パネル：タブとコンテキスト

  • 「コンテキスト」は「ブラウザ」と同じ行に並び、その隣で開きます。
  • 右パネルのタブは常に幅に収まります。長い名前は省略され、枠からはみ出しません。
  • 「コンテキスト」のセクションは縦に並びます：環境、ウィンドウの使用量、計画、圧縮の履歴。
v0.2.4

コンテキスト・計画・圧縮

  • 右パネルに「コンテキスト」タブを追加：モデルのウィンドウの埋まり具合、メッセージとツール呼び出しのコスト、添付ファイルと開いているファイル。
  • 計画：計画モードの回答の手順を一覧で表示し、終わった項目に印を付けます。
  • /compact コマンド：会話を要約にまとめ、以前のメッセージは画面に残ります。
v0.2.3

アプリ内アップデート

  • アプリは自動で更新されます。新しいバージョンは AIDE から直接ダウンロードしてインストールされます。
  • リリースは GitHub でビルドされ署名されます。更新ファイルは署名で検証されます。
  • ウィンドウ右上に作者の名前を表示。
  • サイトに「ダウンロード」ボタンを追加。ワンクリックでインストーラーを取得できます。
v0.1.1

ひとつのウィンドウにスタジオを

エディター

  • CodeMirror 6ベースのエディター：ハイライト、検索、折りたたみ、マルチカーソル、diff。
  • プロジェクトツリー、タブ式ターミナル、Gitパネル、プロジェクト検索。
  • コマンドパレット、最近のプロジェクト、スニペット。
  • コンソール付きの内蔵ブラウザー。写真、動画、PDFもタブで開けます。

AI

  • 許可、操作レポート、トークン集計、元に戻す、「停止」ボタンを備えたエージェント。
  • Ctrl+K で選択したコードを編集し、変更をプレビュー。
  • Vibeモードと、顔と声とスキルを持つ12ロールのクルー。
  • デザインモード：キャンバス、レイヤー、選んだスタックでのプロジェクト作成。
  • MCPサーバー、AGENTS.mdによるプロジェクトのルール、独自のチャットコマンド。

セキュリティとインターフェース

  • APIキーはWindowsの資格情報マネージャーに。
  • 11言語のインターフェース。
