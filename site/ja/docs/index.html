AIDE ドキュメント

AIDEの
使い方

要点だけの短いガイド：初回起動からエージェント用の独自コマンドまで。

はじめに

  1. Node.js 20+、Rust、Windows向けTauri 2の前提環境をインストールします。
  2. プロジェクトフォルダーで npm install、続けて npm run tauri dev を実行します。
  3. コードのフォルダーを開く：Ctrl+O。
  4. 設定でモデルを接続します。APIキーはファイルではなくWindowsの資格情報マネージャーに保存されます。

3つのモード

ウィンドウ上部のスイッチでインターフェース全体が切り替わります。プロジェクト、履歴、エージェントはそのままです。

IDE
CodeMirror 6ベースのエディター、ファイルツリー、タブ式ターミナル、Git、検索。エージェントは右側のチャットにいます。
Vibe
結果を言葉で伝えるだけ。チームリードがタスクを手順に分け、ロールが実行し、QAが確認します。
デザイン
キャンバスでモックアップを組み、「プロジェクトに作成」を押してスタックを選択：HTML、React、Vue、Svelte、Next.js、Astro。

エージェント

  • 許可。ファイルの書き込みやターミナルでのコマンド実行は、あなたが「許可」してから。
  • レポート。返答の最後に「完了：6件の操作 ›」のような操作一覧と、使ったトークン数が表示されます。
  • 元に戻す。編集の前にチェックポイントを作成。「元に戻す」で変更したファイルを復元します。
  • 停止。モデルへのリクエストを即座に中断します。
  • 選択範囲の編集。コードを選択して Ctrl+K：変更が diff で表示され、採用か却下を選べます。

クルー

顔と声とスキルを持つ12のロール：チームリード、デザイン、フロント、バック、QA、DevOps、アナリスト、法務、経理、マーケター、インターン、ムードメーカー。あなたはCEO。タスクを出すと、ロールたちが話し合って作業を分担します。

ファイルの変更やコマンドの実行ができるのは「手」を持つロールだけで、他は助言とレビューを担当します。ロールの操作もエージェントと同じ許可の仕組みを通ります。

ルールとコマンド

プロジェクトのルートに AGENTS.md か CLAUDE.md を置くと、エージェントは作業前にそのルールを読みます。

独自のチャットコマンド：プロンプトを書いたファイル .aide/commands/名前.md を作ると、チャットに /名前 として表示され、$ARGUMENTS はコマンドの後に入力した内容に置き換わります。

キーボードショートカット

Ctrl+Oプロジェクトフォルダーを開く
Ctrl+Sファイルを保存
Ctrl+Wタブを閉じる
Ctrl+Pコマンドパレット
Ctrl+R最近のプロジェクト
Ctrl+Bサイドバーの表示・非表示
Ctrl+Jターミナルの表示・非表示
Ctrl+Shift+Fプロジェクト内を検索
Ctrl+Shift+GGitパネル
Ctrl+K選択したコードをエージェントに編集させる
Escパレット、設定、編集を閉じる
