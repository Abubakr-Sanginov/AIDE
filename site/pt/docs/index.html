AIDE Documentação

Como trabalhar
no AIDE

Guias curtos do essencial: do primeiro uso aos seus próprios comandos para o agente.

Primeiros passos

  1. Instale Node.js 20+, Rust e os pré-requisitos do Tauri 2 para Windows.
  2. Na pasta do projeto, rode npm install e depois npm run tauri dev.
  3. Abra a pasta do seu código: Ctrl+O.
  4. Conecte um modelo nas configurações. A chave de API fica no cofre de credenciais do Windows, não em arquivos.

Três modos

O seletor no topo da janela muda toda a interface. O projeto, o histórico e o agente continuam os mesmos.

IDE
Um editor sobre o CodeMirror 6, árvore de arquivos, terminais em abas, Git e busca. O agente fica no chat à direita.
Vibe
Descreva o resultado com palavras. O team lead divide a tarefa em etapas, os papéis executam e o QA confere.
Design
Monte um mockup no canvas, depois clique em «Criar no projeto» e escolha o stack: HTML, React, Vue, Svelte, Next.js ou Astro.

Agente

  • Permissões. Gravar arquivos e rodar comandos no terminal só depois do seu «Permitir».
  • Relatório. Cada resposta termina com a lista de ações, por exemplo «Concluído: 6 ações ›», e o total de tokens gastos.
  • Desfazer. Antes de qualquer edição é criado um checkpoint. O botão «Desfazer» restaura os arquivos alterados.
  • Parar. Corta a requisição ao modelo na hora.
  • Editar uma seleção. Selecione o código e pressione Ctrl+K: as mudanças aparecem como diff para aceitar ou rejeitar.

Tripulação

Doze papéis com rostos, vozes e habilidades: team lead, design, front, back, QA, DevOps, analista, advogado, contador, marketing, estagiário e piadista. Você é o CEO: define a tarefa, os papéis discutem e dividem o trabalho.

Só os papéis com «mãos» podem alterar arquivos e rodar comandos — os demais aconselham e revisam. As ações deles passam pelas mesmas permissões do agente.

Regras e comandos

Coloque AGENTS.md ou CLAUDE.md na raiz do projeto — o agente lê essas regras antes de trabalhar.

Seus próprios comandos de chat: crie um arquivo .aide/commands/nome.md com o prompt. Ele aparece no chat como /nome, e $ARGUMENTS é trocado pelo que você escrever depois do comando.

Atalhos de teclado

Ctrl+OAbrir uma pasta de projeto
Ctrl+SSalvar o arquivo
Ctrl+WFechar a aba
Ctrl+PPaleta de comandos
Ctrl+RProjetos recentes
Ctrl+BMostrar ou ocultar a barra lateral
Ctrl+JMostrar ou ocultar o terminal
Ctrl+Shift+FBuscar no projeto
Ctrl+Shift+GPainel do Git
Ctrl+KPedir ao agente para editar o código selecionado
EscFechar a paleta, as configurações ou a edição
