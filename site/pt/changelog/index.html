v0.1.1Versão atual

Um estúdio numa janela

Editor

  • Editor sobre o CodeMirror 6: realce, busca, dobra de código, múltiplos cursores, diff.
  • Árvore do projeto, terminais em abas, painel do Git, busca no projeto.
  • Paleta de comandos, projetos recentes, snippets.
  • Navegador integrado com console; fotos, vídeos e PDFs abrem numa aba.

IA

  • Um agente com permissões, relatório de ações, contagem de tokens, desfazer e botão «Parar».
  • Edição do código selecionado com Ctrl+K e prévia das mudanças.
  • Modo Vibe e uma tripulação de doze papéis com rostos, vozes e habilidades.
  • Modo Design: canvas, camadas e criação de projeto no stack escolhido.
  • Servidores MCP, regras do projeto a partir do AGENTS.md e comandos de chat próprios.

Segurança e interface

  • Chaves de API no cofre de credenciais do Windows.
  • Interface em 11 idiomas.
