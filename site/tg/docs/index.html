AIDE Ҳуҷҷатҳо

Чӣ тавр дар AIDE
кор кардан

Дастурҳои кӯтоҳ оид ба асосӣ: аз оғози аввал то фармонҳои худ барои агент.

Оғози кор

  1. Node.js 20+, Rust ва вобастагиҳои Tauri 2 барои Windows-ро насб кунед.
  2. Дар ҷузвдони лоиҳа npm install, баъд npm run tauri dev-ро иҷро кунед.
  3. Ҷузвдони кодро кушоед: Ctrl+O.
  4. Дар танзимот моделро пайваст кунед. Калиди API на дар файлҳо, балки дар анбори маълумоти воридшавии Windows нигоҳ дошта мешавад.

Се реҷа

Гузаргоҳ дар сарлавҳаи равзана тамоми интерфейсро иваз мекунад. Лоиҳа, таърих ва агент ҳамон мемонанд.

IDE
Муҳаррир дар асоси CodeMirror 6, дарахти файлҳо, терминалҳо дар варақаҳо, Git ва ҷустуҷӯ. Агент дар чати тарафи рост аст.
Vibe
Натиҷаро бо калимаҳо тавсиф кунед. Сардори даста вазифаро ба қадамҳо тақсим мекунад, нақшҳо иҷро мекунанд, QA месанҷад.
Дизайн
Дар канвас макет созед, баъд «Дар лоиҳа сохтан»-ро пахш кунед ва стекро интихоб кунед: HTML, React, Vue, Svelte, Next.js ё Astro.

Агент

  • Иҷозатҳо. Навиштани файлҳо ва иҷрои фармонҳо дар терминал танҳо пас аз «Иҷозат»-и шумо.
  • Ҳисобот. Дар охири ҳар ҷавоб рӯйхати амалҳо, масалан «Иҷро шуд: 6 амал ›», ва шумораи токенҳои сарфшуда меояд.
  • Бозгардонӣ. Пеш аз ҳар тағйир нуқтаи назоратӣ сохта мешавад. Тугмаи «Бекор кардан» файлҳои тағйирёфтаро барқарор мекунад.
  • Қатъ. Дархостро ба модел фавран мебурад.
  • Таҳрири интихобшуда. Кодро интихоб кунед ва Ctrl+K-ро пахш кунед: тағйирот ҳамчун diff намоён мешаванд, онҳоро қабул ё рад кардан мумкин аст.

Экипаж

Дувоздаҳ нақш бо чеҳра, овоз ва малака: сардори даста, дизайн, фронт, бэк, QA, девопс, таҳлилгар, ҳуқуқшинос, муҳосиб, маркетолог, таҷрибаомӯз ва ҳазлгӯ. Шумо — CEO: вазифа мегузоред, нақшҳо онро муҳокима ва корро тақсим мекунанд.

Файлҳоро тағйир додан ва фармонҳоро иҷро кардан танҳо нақшҳои «дастдор» метавонанд — дигарон маслиҳат медиҳанд ва месанҷанд. Амалҳои нақшҳо аз ҳамон иҷозатҳое мегузаранд, ки амалҳои агент.

Қоидаҳо ва фармонҳо

AGENTS.md ё CLAUDE.md-ро дар решаи лоиҳа гузоред — агент пеш аз кор ин қоидаҳоро мехонад.

Фармонҳои худи шумо барои чат: файли .aide/commands/ном.md-ро бо матни дархост созед. Дар чат он ҳамчун /ном пайдо мешавад ва ба ҷои $ARGUMENTS он чизе гузошта мешавад, ки пас аз фармон менависед.
