AIDE Docs

How to work
in AIDE

Short guides to the essentials: from the first launch to your own commands for the agent.

Getting started

  1. Install Node.js 20+, Rust and the Tauri 2 prerequisites for Windows.
  2. In the project folder run npm install, then npm run tauri dev.
  3. Open your code folder: Ctrl+O.
  4. Connect a model in the settings. The API key is stored in the Windows credential store, not in files.

Three modes

The switch in the window header changes the whole interface. The project, the history and the agent stay the same.

IDE
An editor on CodeMirror 6, file tree, tabbed terminals, Git and search. The agent lives in the chat on the right.
Vibe
Describe the result in words. The team lead splits the task into steps, the roles do them, QA checks.
Design
Build a mockup on the canvas, then press “Create in project” and pick a stack: HTML, React, Vue, Svelte, Next.js or Astro.

Agent

  • Permissions. Writing files and running terminal commands happen only after you click “Allow”.
  • Report. Each reply ends with a list of actions, e.g. “Done: 6 actions ›”, and the number of tokens spent.
  • Undo. A checkpoint is created before any edit. The “Undo” button restores the changed files.
  • Stop. Cuts the request to the model instantly.
  • Edit a selection. Select code and press Ctrl+K: the changes appear as a diff you can accept or reject.

Crew

Twelve roles with faces, voices and skills: team lead, design, front, back, QA, DevOps, analyst, lawyer, accountant, marketer, intern and joker. You're the CEO: you set the task, the roles discuss it and split the work.

Only roles with “hands” can change files and run commands — the rest advise and review. Role actions go through the same permissions as the agent's.

Rules and commands

Put AGENTS.md or CLAUDE.md in the project root — the agent reads these rules before it starts.

Your own chat commands: create a file .aide/commands/name.md with the prompt. It shows up in chat as /name, and $ARGUMENTS is replaced with whatever you type after the command.

Ctrl+BShow or hide the sidebar
