编辑器。

AIDE 是一间工作室。智能体、设计画布和十二个角色的团队在同一个窗口里工作——由你决定哪些内容进入代码。

* Tauri 2 · Rust · React 19

一个窗口。

03 掌控

密钥
不离开本机

API 密钥保存在 Windows 凭据管理器中。危险操作需要你确认，智能体每次修改前都会创建检查点，“停止”立即中断请求。

  • 0字节密钥
    留在仓库
  • 100%本地运行，
    除了你的模型
  • 1 次点击即可
    完全停止
