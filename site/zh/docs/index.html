如何使用
AIDE

核心功能的简短指南：从首次启动到为智能体编写自己的命令。

快速上手

  1. 安装 Node.js 20+、Rust 以及 Windows 版 Tauri 2 依赖。
  2. 在项目文件夹中运行 npm install，然后运行 npm run tauri dev。
  3. 打开代码文件夹：Ctrl+O。
  4. 在设置中连接模型。API 密钥保存在 Windows 凭据管理器中，而不是文件里。

三种模式

窗口顶部的切换器会改变整个界面，而项目、历史记录和智能体保持不变。

IDE
基于 CodeMirror 6 的编辑器、文件树、标签页式终端、Git 和搜索。智能体在右侧聊天中。
Vibe
用文字描述想要的结果。组长把任务拆成步骤，角色完成，QA 验收。
设计
在画布上搭出原型，然后点击“在项目中创建”并选择技术栈：HTML、React、Vue、Svelte、Next.js 或 Astro。

智能体

  • 权限。写文件和在终端执行命令，都要等你点“允许”。
  • 报告。每次回复末尾都有操作列表，例如“已完成：6 个操作 ›”，以及消耗的 token 数。
  • 撤销。每次修改前都会创建检查点。“撤销”按钮可恢复被修改的文件。
  • 停止。立即中断发给模型的请求。
  • 修改选中内容。选中代码后按 Ctrl+K：修改以 diff 显示，可接受或拒绝。

团队

十二个有面孔、声音和技能的角色：组长、设计、前端、后端、QA、运维、分析师、法务、会计、市场、实习生和开心果。你是 CEO：你布置任务，角色们讨论并分工。

只有“有手”的角色才能修改文件和执行命令，其余角色负责建议和检查。角色的操作与智能体走同样的权限流程。

规则与命令

把 AGENTS.md 或 CLAUDE.md 放在项目根目录——智能体开始工作前会读取这些规则。

自定义聊天命令：创建文件 .aide/commands/名称.md 并写入提示词。它会在聊天中显示为 /名称，$ARGUMENTS 会替换为你在命令后输入的内容。

快捷键

Ctrl+O打开项目文件夹
Ctrl+S保存文件
Ctrl+W关闭标签页
Ctrl+P命令面板
Ctrl+R最近的项目
Ctrl+B显示或隐藏侧边栏
Ctrl+J显示或隐藏终端
Ctrl+Shift+F在项目中搜索
Ctrl+Shift+GGit 面板
Ctrl+K让智能体修改选中的代码
Esc关闭命令面板、设置或修改
