AIDE 更新内容

版本
历史

编辑器的每个新版本都会出现在这里。

v0.2.6当前版本

Vibe：上下文紧邻浏览器，密钥来自环境变量

  • 在 Vibe 和「设计」中，右侧有「上下文」和「浏览器」标签：计划和窗口占用显示在页面旁边。
  • 形如 $T3_DEEPAI_TOKEN 的智能体密钥现在会从环境变量展开，而不再把 $NAME 当作文本保存——403「Model transport authentication required」错误已消失。
v0.2.5

右侧面板：标签与上下文

  • 「上下文」与「浏览器」同排，并在其旁边打开。
  • 右侧面板的标签始终适配宽度：过长的名称会被省略，不会超出边缘。
  • 「上下文」的各分区依次排列：环境、窗口占用、计划与压缩历史。
v0.2.4

上下文、计划与压缩

  • 右侧面板新增「上下文」标签：模型窗口占用、消息与工具调用的开销、附件和当前文件。
  • 计划：计划模式回答中的步骤以列表显示，已完成的项目会打勾。
  • /compact 命令：对话压缩成一份摘要，之前的消息仍留在屏幕上。
v0.2.3

应用内更新

  • 应用会自行更新：新版本直接从 AIDE 下载并安装。
  • 版本在 GitHub 上构建并签名，更新文件会用签名校验。
  • 窗口右上角显示作者名字。
  • 网站上新增“下载”按钮，一键获取安装程序。
v0.1.1

一个窗口里的工作室

编辑器

  • 基于 CodeMirror 6 的编辑器：高亮、搜索、折叠、多光标、diff。
  • 项目文件树、标签页式终端、Git 面板、项目搜索。
  • 命令面板、最近的项目、代码片段。
  • 带控制台的内置浏览器；照片、视频和 PDF 可在标签页中打开。

AI

  • 带权限、操作报告、token 统计、撤销和“停止”按钮的智能体。
  • 用 Ctrl+K 修改选中代码，并预览改动。
  • Vibe 模式，以及由十二个有面孔、声音和技能的角色组成的团队。
  • 设计模式：画布、图层，以及在所选技术栈中创建项目。
  • MCP 服务器、来自 AGENTS.md 的项目规则和自定义聊天命令。

安全与界面

  • API 密钥保存在 Windows 凭据管理器中。
  • 界面支持 11 种语言。
