v0.1.1当前版本

一个窗口里的工作室

编辑器

  • 基于 CodeMirror 6 的编辑器：高亮、搜索、折叠、多光标、diff。
  • 项目文件树、标签页式终端、Git 面板、项目搜索。
  • 命令面板、最近的项目、代码片段。
  • 带控制台的内置浏览器；照片、视频和 PDF 可在标签页中打开。

AI

  • 带权限、操作报告、token 统计、撤销和“停止”按钮的智能体。
  • 用 Ctrl+K 修改选中代码，并预览改动。
  • Vibe 模式，以及由十二个有面孔、声音和技能的角色组成的团队。
  • 设计模式：画布、图层，以及在所选技术栈中创建项目。
  • MCP 服务器、来自 AGENTS.md 的项目规则和自定义聊天命令。

安全与界面

  • API 密钥保存在 Windows 凭据管理器中。
  • 界面支持 11 种语言。
