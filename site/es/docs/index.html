AIDE Documentación

Cómo trabajar
en AIDE

Guías cortas de lo esencial: desde el primer arranque hasta tus propios comandos para el agente.

Primeros pasos

  1. Instala Node.js 20+, Rust y los requisitos de Tauri 2 para Windows.
  2. En la carpeta del proyecto ejecuta npm install y luego npm run tauri dev.
  3. Abre la carpeta con tu código: Ctrl+O.
  4. Conecta un modelo en los ajustes. La clave de API se guarda en el almacén de credenciales de Windows, no en archivos.

Tres modos

El interruptor de la cabecera de la ventana cambia toda la interfaz. El proyecto, el historial y el agente siguen siendo los mismos.

IDE
Un editor sobre CodeMirror 6, árbol de archivos, terminales en pestañas, Git y búsqueda. El agente está en el chat de la derecha.
Vibe
Describe el resultado con palabras. El team lead divide la tarea en pasos, los roles los hacen y QA lo revisa.
Diseño
Arma una maqueta en el lienzo, pulsa «Crear en el proyecto» y elige un stack: HTML, React, Vue, Svelte, Next.js o Astro.

Agente

  • Permisos. Escribir archivos y ejecutar comandos en la terminal, solo después de tu «Permitir».
  • Informe. Cada respuesta termina con la lista de acciones, por ejemplo «Hecho: 6 acciones ›», y los tokens gastados.
  • Deshacer. Antes de cualquier cambio se crea un punto de control. El botón «Deshacer» restaura los archivos modificados.
  • Detener. Corta al instante la petición al modelo.
  • Editar una selección. Selecciona código y pulsa Ctrl+K: los cambios aparecen como diff para aceptarlos o rechazarlos.

Tripulación

Doce roles con caras, voces y habilidades: team lead, diseño, front, back, QA, DevOps, analista, abogado, contable, marketing, becario y bromista. Tú eres el CEO: planteas la tarea, los roles la discuten y se reparten el trabajo.

Solo los roles con «manos» pueden cambiar archivos y ejecutar comandos; el resto aconseja y revisa. Sus acciones pasan por los mismos permisos que las del agente.

Reglas y comandos

Pon AGENTS.md o CLAUDE.md en la raíz del proyecto: el agente leerá esas reglas antes de trabajar.

Tus propios comandos de chat: crea un archivo .aide/commands/nombre.md con el prompt. Aparecerá en el chat como /nombre, y $ARGUMENTS se sustituye por lo que escribas después del comando.

Atajos de teclado

Ctrl+OAbrir una carpeta de proyecto
Ctrl+SGuardar el archivo
Ctrl+WCerrar la pestaña
Ctrl+PPaleta de comandos
Ctrl+RProyectos recientes
Ctrl+BMostrar u ocultar la barra lateral
Ctrl+JMostrar u ocultar la terminal
Ctrl+Shift+FBuscar en el proyecto
Ctrl+Shift+GPanel de Git
Ctrl+KQue el agente edite el código seleccionado
EscCerrar la paleta, los ajustes o la edición
