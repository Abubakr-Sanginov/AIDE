# Проверка вживую

Что в AIDE написано и покрыто тестами, но ни разу не запускалось по-настоящему на этом компьютере. Пройдите пункты по порядку и отмечайте, что сломалось: пишите номер пункта и что увидели.
Везде начинайте с режима разрешений **«Спрашивать»**, чтобы видеть каждое действие агента.

## 1. Обновление из приложения (3 минуты)
1. Настройки → Обновления → «Проверить».
2. Если есть новая версия: «Установить и перезапустить». Приложение закрывается и открывается снова.
3. Настройки → Обновления: номер версии новый.
**Ждём:** без ошибок, версия выросла. **Если нет:** запишите текст ошибки.

## 2. Принудительная отправка (2 минуты)
1. В режиме «Агент» дайте длинную задачу (например, «разбери проект и опиши каждый файл»).
2. Пока агент работает, напишите два сообщения: они встанут в очередь.
3. Нажмите стрелку у второго.
**Ждём:** агент остановился, второе сообщение отправилось первым, первое осталось в очереди.

## 3. Сценарий `/scenario` (5 минут)
1. Откройте любой сайт проекта (запустите его).
2. В режиме «Агент» напишите: `/scenario открыть главную, нажать на первую кнопку, проверить что нет ошибок`.
**Ждём:** агент открывает страницу во встроенном браузере, проходит шаги, в конце таблица «Шаг | Ожидалось | Получилось | Статус» и результаты для телефона, планшета и компьютера.

## 4. Режим «Компьютер» и журнал (10 минут)
1. Вкладка «Компьютер» → согласие → режим разрешений «Спрашивать».
2. Откройте Блокнот. Задача: «Найди окно Блокнота и напечатай слово тест».
3. Подтверждайте каждое действие. **Мышь в левый верхний угол останавливает агента.**
4. Настройки → «Журнал «Компьютера»»: видны клики, ввод (только длина текста), фокус окна.
**Ждём:** агент видит экран, находит Блокнот, печатает; в журнале нет самого текста. На модели без зрения агент скажет, что картинки недоступны.

## 5. Голосовое управление (10 минут)
Нужен ключ Groq (Настройки → Голос).
1. Настройки → Голос → «Управлять компьютером голосом», клавиша `Ctrl+Shift+Space`.
2. Зажмите клавиши, скажите «открой блокнот», отпустите. Высокий сигнал при начале, низкий при конце.
3. Через 3 секунды команда уходит агенту; нажмите клавишу снова в эти 3 секунды: команда отменяется.
**Ждём:** сигналы слышны, плашка «Слушаю…», распознанный текст в уведомлении. **Если нет:** проверьте микрофон Windows и ключ Groq.

## 6. Студия 3D (15 минут)
Нужны Blender и его MCP-пресет (Настройки → MCP).
1. Вкладка «Студия 3D» в режиме Vibe.
2. Задача: «Сделай низкополигональное дерево: ствол, крона из нескольких частей, материалы».
3. Через 5–10 минут: посмотрите превью.
**Ждём:** модель не из одних кубов, у частей разные материалы; агент сравнивал с образцами и сам что-то переделал.

## 7. Подписки ИИ (3 минуты)
1. Настройки → «Подписки ИИ»: найдены ваши агенты, тарифы и замаскированные аккаунты.
2. «Использовать его ключ в AIDE» у любого агента кроме Claude Code, Codex и Gemini.
3. В окне виден адрес, куда уйдёт ключ.
**Ждём:** модели подтянулись, чат отвечает. DeepAI Code должен быть запущен и обновлён.

---
Если что-то сломалось, скопируйте номер пункта и сообщение об ошибке: по ним проще всего найти причину.
