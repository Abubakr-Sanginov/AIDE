# Agent Skills в AIDE

Навыки (skills) — папки с `SKILL.md` (frontmatter `name` / `description` + инструкции) и справочными файлами, формат каталога https://skills.sh/. AIDE использует их только как текст: скрипты из навыков не скачиваются и не запускаются.

## Откуда берутся навыки

| Где | id | Удаление из UI |
|---|---|---|
| Встроенные (эта папка, вшиты в бинарник) | `builtin:<name>` | нет, только выключить |
| Глобальные: `<app data>/skills/<name>/` | `global:<name>` | да |
| Проект: `.aide/skills/<name>/` | `project:.aide/skills/<name>` | да |
| Проект: `.agents/skills/`, `.claude/skills/` (ставит `npx skills add`) | `project:…` | нет, только выключить |

Одинаковые по имени навыки: побеждает копия проекта, затем глобальная, затем встроенная. Выключенные id хранятся в `<app data>/skills_state.json`.

Встроенные: `verify-before-done`, `careful-code-changes`, `secure-coding`, `writing-tests`, `debugging`, `react-frontend` (написаны для AIDE), `frontend-design`, `webapp-testing` (снимки anthropics/skills, см. SOURCES.md).

## Установка из skills.sh

Настройки → Навыки → «Каталог skills.sh». Поиск идёт через `https://skills.sh/api/search`, можно вставить ссылку skills.sh / github.com, `owner/repo[/skill]` или `npx skills add … --skill …`. Предпросмотр показывает текст SKILL.md и список файлов до установки. Вся сеть — в Rust (`src/skills_remote.rs`):

- хосты только `skills.sh`, `api.github.com`, `raw.githubusercontent.com` (https, редиректы проверяются);
- версия фиксируется по SHA коммита, он записывается в `.aide-source.json`;
- SKILL.md ≤ 64 КБ, до 80 справочных текстовых файлов ≤ 128 КБ каждый, всего ≤ 1,5 МБ; папка `scripts/`, shell-скрипты и бинарные файлы пропускаются;
- пути проверяются (без `..`, скрытых сегментов и выхода за папку навыков), запись через временную папку.

## Как навыки попадают к модели (прогрессивное раскрытие)

1. В системный промпт идёт только индекс: `id — описание` (до 170 символов на навык, до 3 600 символов всего).
2. Агент и режим «План» имеют инструменты `list_skills` и `read_skill(id, file?)` — модель сама загружает полный SKILL.md или справочный файл (до 24 000 символов за вызов).
3. Для слабых моделей, которые редко зовут инструменты, самый подходящий навык подключается автоматически по релевантности (имя навыка в запросе, ключевые слова RU/EN, слова описания): 1 навык до 5 000 символов в агенте, до 2 навыков / 8 000 символов в обычном чате.

Навыки не отменяют запрос пользователя, правила проекта, формат ответа, режим чтения и разрешения: это прописано в системном тексте вокруг них.

Навыки, назначенные ролям «Экипажа» и разделу «Дизайн» (`src/features/design/skills`), работают как раньше, отдельно от этого механизма.
