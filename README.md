# AIDE

Редактор кода с ИИ-студией внутри: агент, дизайн-холст и команда из двенадцати ролей в одном окне.
Собран с нуля на Tauri 2, Rust и React 19 — без форка VS Code и без Electron.

## Что это такое

AIDE — настольное приложение для Windows, в котором редактор, терминал, Git, языковые серверы и ИИ-агент работают
в одном окне. Агент не просто отвечает в чат: он читает проект, правит файлы, запускает команды и проверяет
результат, а каждое его действие видно, оценено в токенах и отменяется одной кнопкой.

Три режима в одном окне:

- **IDE** — обычная работа с кодом: дерево проекта, вкладки, терминал, Git, поиск.
- **Vibe** — интерфейс по описанию: агент собирает экран и сразу показывает его.
- **Дизайн** — визуальный холст для HTML и CSS по экранам.

## Возможности

### Редактор

- CodeMirror 6: подсветка для десятков языков, номера строк, автодополнение, поиск и замена, мультикурсор, сворачивание.
- Языковые серверы (LSP): подсказки по типам, ошибки, переход к определению и обратно, переименование, форматирование.
- Просмотр картинок, PDF и шрифтов прямо во вкладке.
- Merge-view для конфликтов Git: принять свою или чужую сторону кнопкой.

### Агент

- Читает проект перед работой: карта файлов, определения, поиск по смыслу — не по одному имени.
- Инструменты: чтение и запись файлов, правки по фрагменту, поиск по коду, дерево проекта, терминал, диагностика,
  загрузка страниц, навыки.
- Разрешения: запись, команды и сеть — только с подтверждением, если вы не включили полный доступ.
- Чекпоинты: перед правками снимается состояние файлов, кнопка «Отменить» возвращает всё назад.
- Очередь сообщений: новое сообщение встаёт в очередь, а стрелка рядом отправляет его немедленно, останавливая
  текущий ответ.

### Экипаж

Двенадцать ролей с разными зонами ответственности: тимлид, дизайн, фронтенд, бэкенд, QA, девопс, аналитик, юрист,
бухгалтер, маркетолог, стажёр и шутник. Менять файлы и запускать команды могут только роли «с руками» — остальные
советуют и проверяют. Вы решаете, что из предложенного попадёт в код.

### Терминал и Git

- Настоящий pty: интерактивные программы, цвета, стрелки, Ctrl+C, несколько вкладок.
- Панель Git: изменённые файлы, построчный diff, ветка, история, коммит.

### Проверки качества

После правок AIDE сама запускает проверки проекта и присылает вывод, если что-то сломалось.

| Изменения | Проверка |
|---|---|
| JS / TS | `typecheck` из package.json или `tsc --noEmit`, затем `lint` и `test`, если объявлены |
| Rust | `cargo check` в корне или в `src-tauri/` |
| Go | `go vet ./...` |
| Python | `python -m py_compile` по изменённым файлам |

## Требования

Для работы с готовым установщиком:

- Windows 10 или 11, 64-бит.
- WebView2 — на актуальных сборках уже установлен.

Для сборки из исходников дополнительно:

- Node.js 20 или новее.
- Rust (stable) и зависимости Tauri 2 для Windows: Microsoft C++ Build Tools и WebView2.

Для работы агента нужен доступ к модели: ключ облачного провайдера или локальный сервер вроде Ollama.

## Установка

### Готовый установщик

1. Откройте [страницу загрузки](https://aide-site-nine.vercel.app/#start) или
   [релизы](https://github.com/Abubakr-Sanginov/AIDE/releases).
2. Скачайте `AIDE_<версия>_x64-setup.exe` и запустите.
3. Windows покажет предупреждение SmartScreen: установщик не подписан платным сертификатом издателя. Это не вирус;
   подпись самих обновлений проверяется отдельно, внутри приложения.

### Сборка из исходников

```bash
git clone https://github.com/Abubakr-Sanginov/AIDE.git
cd AIDE
npm install
npm run tauri dev      # режим разработки с горячей перезагрузкой
npm run tauri build    # установщик: NSIS и MSI в папке bundle
```

### Первый запуск

1. Откройте папку проекта: `Ctrl+O`.
2. В настройках подключите модель: провайдер, адрес, ключ. Ключ сохраняется в хранилище учётных данных Windows —
   в файлы проекта он не попадает.
3. Либо запустите модель локально: «Настройки → Локальные модели» сами найдут Ollama и LM Studio.
4. Задайте задачу в чате справа.

## Настройка проекта

### Правила для агента

Положите `AGENTS.md` в корень проекта — агент прочитает его до начала работы. Файл `CLAUDE.md` тоже
поддерживается.

### Свои команды в чате

Создайте `.aide/commands/имя.md` с текстом запроса. В чате команда появится как `/имя`, а вместо `$ARGUMENTS`
подставится всё, что вы напишете после неё.

### Свои проверки

```json
{ "commands": ["npm run lint", "npm test"], "timeoutSeconds": 300 }
```

Файл `.aide/checks.json`. Значение `{ "enabled": false }` отключает проверки для проекта. Команды из проекта
запускаются только с вашего разрешения, кроме режима «Полный доступ». Код: `src-tauri/src/verify.rs`.

## Языковые серверы

В файлах, для которых на компьютере есть языковой сервер, редактор подсказывает по типам, показывает описание при
наведении, подчёркивает ошибки, умеет переход к определению (`F12` или `Ctrl`+клик), ссылки (`Shift+F12`),
переименование (`F2`) и форматирование (`Shift+Alt+F`).

| Язык | Сервер | Установка |
|---|---|---|
| TypeScript / JavaScript | typescript-language-server | `npm install -g typescript-language-server typescript` |
| Rust | rust-analyzer | `rustup component add rust-analyzer` |
| Python | pyright | `npm install -g pyright` |
| Go | gopls | `go install golang.org/x/tools/gopls@latest` |
| C / C++ | clangd | `winget install LLVM.LLVM` |
| CSS, HTML, JSON | vscode-langservers-extracted | `npm install -g vscode-langservers-extracted` |

Статус каждого сервера и команда установки — в «Настройки → Языковые серверы». AIDE запускает только установленные
программы (PATH, `~/.cargo/bin`, глобальный npm, `~/go/bin`) и никогда не берёт их из папки проекта.

Агент видит те же ошибки: инструмент `get_diagnostics` вызывается после правок. Код: `src-tauri/src/lsp.rs`,
`src/features/lsp/`.

## Локальные модели

AIDE работает с моделями на вашем компьютере: без ключа API и интернета, код не покидает машину. «Настройки →
Локальные модели» сами находят запущенные Ollama (`127.0.0.1:11434`) и LM Studio (`127.0.0.1:1234`), показывают их
модели с размером, длиной контекста и пометкой «инструменты» и выбирают модель одним нажатием. Другой порт задаётся
в поле «Адрес» — только адреса этого компьютера.

- **Ollama:** установите, запустите приложение или `ollama serve`, скачайте модель: `ollama pull qwen2.5-coder:7b`.
- **LM Studio:** Developer → Start Server, загрузите модель.
- **Другой OpenAI-совместимый сервер** (llama.cpp, vLLM): «Настройки → Агент → +», адрес вида `http://127.0.0.1:8080/v1`,
  ключ пустой — провайдер получит префикс `local-` и будет работать без ключа.

**Компактный агент** включён для локальных моделей: короткая инструкция и только основные инструменты. Небольшие
модели справляются с ним заметно лучше — на тестовой машине модель 12B с компактным агентом решила задачу за 28
секунд, без него за три минуты не ответила.

Контекст агента — от 8K, лучше 16K и выше: в Ollama `OLLAMA_CONTEXT_LENGTH=16384` до запуска, в LM Studio —
«Context Length» при загрузке модели. Кнопка «Контекст 16K» у модели Ollama делает то же без перезапуска сервера:
создаёт копию `<модель>-aide-16k` с параметром `num_ctx 16384`. Веса не скачиваются, копию можно удалить, исходная
модель не затрагивается. Код: `src-tauri/src/local_models.rs`, `src/features/settings/LocalModelsSection.tsx`.

## Индекс кода

AIDE читает проект один раз и держит в памяти его карту: определения (функции, классы, типы, методы, константы) и
ранжированный поиск по фрагментам файлов. Имена разбиваются по `camelCase` и `snake_case`, имена определений и пути
файлов весят больше обычного текста, а файлы переводов, снимков и сгенерированные — меньше. Запрос «permission gate»
находит `PermissionGate.tsx`, «run shell command» — `run_shell_command` в `terminal.rs`.

- **Агент** получает три инструмента: `search_code`, `find_symbol`, `project_map`.
- **Редактор:** в палитре команд (`Ctrl+P`) запрос, начинающийся с `@`, ищет определения: `@PermissionGate`.
- **Настройки → Индекс кода:** сколько файлов и определений, перестроить индекс, проверить поиск.

Индекс обновляется перед каждым запросом по размеру и времени изменения файлов (~0,15 с на 300 файлов), поэтому правки
агента видны сразу. На этом репозитории первая сборка занимает около двух секунд. Не индексируются: `.gitignore`,
`node_modules`, папки сборки, скрытые папки (кроме `.github`), бинарные, минифицированные и очень большие файлы,
`.env`, символические ссылки. Код: `src-tauri/src/code_index.rs`.

## Обновления и релизы

Приложение само сверяет версию с релизом на GitHub и предлагает обновиться; файлы обновления проверяются подписью.

Порядок выпуска новой версии:

1. Поднять версию в `package.json`, `package-lock.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`.
2. Закоммитить и поставить тег с тем же номером: `git tag -a v0.2.4 -m "AIDE 0.2.4"`.
3. Отправить тег: `git push origin v0.2.4`.

GitHub Actions соберёт установщик, подпишет пакет обновления и опубликует релиз. Нужен секрет репозитория
`TAURI_SIGNING_PRIVATE_KEY` с приватным ключом подписи. Подробнее — в [RELEASE.md](RELEASE.md).

## Структура проекта

```
src/
  app/        App.tsx — корень: хоткеи, подписки на события Tauri
  shell/      оболочка: TitleBar, Sidebar, RightPanel, StatusBar, ResizeHandle
  features/   редактор, чат, проводник, поиск, настройки, терминал, палитра, дизайн, vibe, git, браузер
  stores/     состояние на Zustand
  api/        обёртки над командами Tauri
  lib/        утилиты и переводы
src-tauri/
  src/        команды: fs, terminal, git, lsp, code_index, verify, ai_service, agent_service
  exthost/    хост расширений
site/         сайт: 11 языков, генератор страниц, сборка под Vercel
tests/        тесты на Node test runner
```

Импорты — через алиас `@/` (это `src/`). Окно без нативной рамки, заголовок рисует `shell/TitleBar`.

## Безопасность

- Ключи API хранятся в хранилище учётных данных Windows, отдельно для каждого провайдера, и не попадают в файлы
  проекта, репозиторий и журналы.
- Запись файлов, команды терминала и сетевые запросы выполняются после подтверждения.
- Обновления проверяются криптографической подписью.
- Телеметрии нет: приложение не отправляет статистику использования. Наружу уходит только запрос к выбранной вами
  модели, а с локальной моделью — ничего.
