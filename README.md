# AIDE

Собственный редактор кода с ИИ-функциями — с нуля, без форка VS Code.

## Стек

- **Tauri 2** (Rust-бэкенд) + **React 19** + **TypeScript**
- **Tailwind CSS 4**, **Zustand**, **lucide-react**
- Редактор: CodeMirror 6 (с Этапа 3)

## Запуск

```bash
npm install
npm run tauri dev
```

## План разработки

| Этап | Содержание | Статус |
|---|---|---|
| 1 | Каркас: layout, вкладки, хоткеи | ✅ готов |
| 2 | Файловая система: Tauri-команды, дерево проекта, watcher | ✅ готов |
| 3 | CodeMirror 6: подсветка, номера строк, поиск | ⬜ |
| 4 | ИИ-чат: стриминг, контекст активного файла, API-ключи | ⬜ |
| 5 | Inline edit (Ctrl+K): diff-превью, accept/reject | ⬜ |

## Горячие клавиши

- `Ctrl+O` — открыть папку проекта (нативный диалог)
- `Ctrl+S` — сохранить активный файл
- `Ctrl+B` — показать/скрыть боковую панель
- `Ctrl+W` — закрыть вкладку

## Структура (v2)

```
src/
  app/        корень приложения, хоткеи, подписки
  shell/      оболочка: TitleBar, ActivityBar, Sidebar, RightPanel, StatusBar, ResizeHandle
  features/   editor · chat · explorer · search · settings · terminal · palette · welcome
  stores/ api/ lib/ i18n/   состояние, Tauri-API, утилиты, переводы
  styles/     index.css — токены дизайн-системы «Graphite & Signal»
```

Импорты — через алиас `@/` (= `src/`). Окно без нативной рамки (`decorations: false`), заголовок — `shell/TitleBar`.

## Самопроверка агента

После правок агент сам проверяет проект, прежде чем сдать работу: запускает быстрые проверки, а если они падают —
получает вывод ошибок и исправляет код (до 3 попыток). Переключатель «Проверка» — рядом с правами агента в чате.

Что запускается (автоматически, по изменённым файлам):

| Изменения | Проверка |
|---|---|
| JS/TS | `typecheck` из package.json или `tsc --noEmit`, затем `lint` и `test`, если есть |
| Rust | `cargo check` (в корне или в `src-tauri/`) |
| Go | `go vet ./...` |
| Python | `python -m py_compile` изменённых файлов |

Свои команды для проекта — в `.aide/checks.json`:

```json
{ "commands": ["npm run lint", "npm test"], "timeoutSeconds": 300 }
```

`{ "enabled": false }` отключает проверки для проекта. Команды из проекта запускаются только с вашего разрешения
(кроме режима «Полный доступ»). Код: `src-tauri/src/verify.rs`.

## Языковые серверы (LSP)

В файлах, для которых на компьютере есть языковой сервер, редактор подсказывает по типам, показывает описание при
наведении, подчёркивает ошибки (они же попадают в «Проблемы» и счётчик внизу), умеет переход к определению
(F12 или Ctrl+клик), ссылки (Shift+F12), переименование (F2) и форматирование (Shift+Alt+F).

| Язык | Сервер | Установка |
|---|---|---|
| TypeScript / JavaScript | typescript-language-server | `npm install -g typescript-language-server typescript` |
| Rust | rust-analyzer | `rustup component add rust-analyzer` |
| Python | pyright | `npm install -g pyright` |
| Go | gopls | `go install golang.org/x/tools/gopls@latest` |
| C / C++ | clangd | `winget install LLVM.LLVM` |
| CSS, HTML, JSON | vscode-langservers-extracted | `npm install -g vscode-langservers-extracted` |

Статус каждого сервера и команда установки — в «Настройки → Языковые серверы». AIDE запускает только установленные
программы (PATH, `~/.cargo/bin`, глобальный npm, `~/go/bin`) и никогда не берёт их из папки проекта.

Агент видит те же ошибки: инструмент `get_diagnostics` (весь проект или один файл) вызывается после правок кода.
Код: `src-tauri/src/lsp.rs`, `src/features/lsp/`.

## Локальные модели (Ollama, LM Studio)

AIDE работает с моделями на вашем компьютере: без ключа API и интернета, код не покидает машину.
«Настройки → Локальные модели» сами находят запущенные Ollama (`127.0.0.1:11434`) и LM Studio (`127.0.0.1:1234`),
показывают их модели с размером, длиной контекста и пометкой «инструменты» (агенту нужны модели, которые умеют их
вызывать) и выбирают модель одним нажатием. Другой порт — в поле «Адрес» (только адреса этого компьютера).

- **Ollama:** установите, запустите приложение или `ollama serve`, скачайте модель, например `ollama pull qwen2.5-coder:7b`.
- **LM Studio:** Developer → Start Server, загрузите модель.
- Любой другой OpenAI-совместимый сервер на этом компьютере (llama.cpp, vLLM): «Настройки → Агент → +», адрес вида
  `http://127.0.0.1:8080/v1`, ключ пустой — провайдер получит префикс `local-` и тоже будет работать без ключа.

**Компактный агент** (включён для локальных моделей, переключатель — на той же странице): короткая инструкция
и только основные инструменты (файлы, поиск, терминал, ошибки анализатора, вопросы, навыки), короткие ответы
инструментов. Небольшие модели с ним справляются заметно лучше: на тестовой машине модель 12B с компактным агентом
решила задачу за 28 с, без него за 3 минуты не ответила.

Контекст агента — от 8K, лучше 16K+: Ollama — `OLLAMA_CONTEXT_LENGTH=16384` до запуска, LM Studio — «Context Length»
при загрузке модели.

Кнопка **«Контекст 16K»** у модели Ollama делает то же без перезапуска сервера: создаёт копию `<модель>-aide-16k` с
параметром `num_ctx 16384` (через `/api/create`). Ничего не скачивается — копия использует те же веса. Перед созданием
AIDE объясняет, что произойдёт; копию (и только её, по имени `…-aide-<N>k`) можно удалить кнопкой «Удалить копию»,
исходная модель не затрагивается. Проверено на реальной Ollama: `/api/ps` показывает контекст 16384 без переменной
окружения. Код: `src-tauri/src/local_models.rs`, `src/features/settings/LocalModelsSection.tsx`.

## Индекс кода

AIDE читает проект один раз и держит в памяти его карту: определения (функции, классы, типы, методы, константы) и
ранжированный поиск по фрагментам файлов. Имена разбиваются по `camelCase` и `snake_case`, имена определений и пути
файлов весят больше обычного текста, а файлы переводов, снимков и сгенерированные — меньше, чтобы не вытеснять код.
Запрос «permission gate» находит `PermissionGate.tsx`, «run shell command» — `run_shell_command` в `terminal.rs`.

- **Агент** получает три инструмента: `search_code` (поиск по словам и именам), `find_symbol` (где определено имя),
  `project_map` (обзор: в большом проекте — по папкам, в папке или маленьком проекте — файлы и их определения).
- **Редактор:** в палитре команд (Ctrl+P) запрос, начинающийся с `@`, ищет определения: `@shell command`, `@PermissionGate`.
- **Настройки → Индекс кода:** сколько файлов, строк и определений, перестроить индекс, проверить поиск.

Индекс обновляется перед каждым запросом (сравнение размера и времени изменения файлов, ~0,15 с на 300 файлов), поэтому
правки агента видны сразу. На репозитории AIDE (327 файлов, ~70 тыс. строк) первая сборка занимает около 2 секунд.
Не индексируются: то, что в `.gitignore`, `node_modules`, папки сборки, скрытые папки (кроме `.github`), бинарные,
минифицированные и очень большие файлы, файлы `.env`, символические ссылки. Поддерживаемые языки определений:
TypeScript/JavaScript (+ Vue, Svelte, Astro), Python, Rust, Go, Java/Kotlin/C#, C/C++, Swift/PHP/Ruby/Lua, SQL, shell,
заголовки Markdown. Код: `src-tauri/src/code_index.rs`.
